# همه‌یاب (EverySearch)

جستجوی فوری همه فایل‌های اندروید، شبیه Everything ویندوز.

## دانلود
آخرین نسخه: **[دانلود APK از بخش Releases](https://github.com/doritaha/EverySearch/releases/latest)**

## نصب
1. فایل `EverySearch-v*.apk` را از لینک بالا روی گوشی دانلود کنید.
2. نصب از «منابع ناشناس» را برای مرورگر یا مدیر فایل مجاز کنید و APK را نصب کنید.
3. در اولین اجرا «دسترسی به همه فایل‌ها» را بدهید.
4. (اختیاری) برای جستجو در فایل‌های سیستمی، از منوی ⋮ گزینه روت را روشن کنید.

اندروید ۸ به بالا (minSdk 26).

## امکانات
- نمایه‌سازی کل حافظه داخلی و کارت حافظه؛ جستجو هم‌زمان با تایپ
- با روت (Magisk / KernelSU): `/system`، `/data`، `/vendor` و `Android/data` و `Android/obb` هم جستجو می‌شوند (منوی ⋮)
- دسته‌ها: پوشه، فیلم، صوت، تصویر، PDF، سند، فشرده، برنامه (APK)، سایر
- پیش‌نمایش عکس و فیلم: تصویر بندانگشتی در فهرست و نمای گالری (شبکه‌ای) در دسته‌های «تصویر» و «فیلم»
- مرتب‌سازی بر اساس نام / حجم / تاریخ / مسیر
- روی هر نتیجه: باز کردن، رفتن به پوشه فایل، کپی به…، انتقال به…، اشتراک، تغییر نام، کپی مسیر، حذف
- مرورگر پوشه با انتخاب چندتایی، پوشه جدید و نوار «چسباندن اینجا»

## دستور جستجو
| مثال | معنی |
|---|---|
| `سفر شمال` | نام شامل هر دو کلمه |
| `*.pdf`، `IMG_2024*` | ستاره و علامت سؤال |
| `dcim/ .jpg` | کلمه‌ای که `/` دارد در کل مسیر جستجو می‌شود |
| `video !whatsapp` | `!` یعنی حذف از نتایج |

## ساخت (Build)
JDK 17 + Android SDK 35:
```
gradlew assembleRelease
```
اگر Gradle روی ویندوز خطای `Unable to establish loopback connection` داد:
`set JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:\gtmp`
